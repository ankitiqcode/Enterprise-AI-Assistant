# Enterprise AI Assistant

An enterprise-grade AI assistant built with FastAPI, Next.js, PostgreSQL, and Generative AI.

## Features

- Authentication
- AI Chat
- RAG
- Document Upload
- Knowledge Base
- Analytics
- Admin Dashboard
- PostgreSQL
- Docker
- JWT Authentication

Frontend:
- Next.js
- React
- Tailwind CSS

Database:
- PostgreSQL

AI:
- Gemini/OpenAI
- LangChain

- Docker
